# Finish and accessibility audit (2026-10-04)

Scope: every route (`/`, `/accessibility-statement`, `/privacy-policy`, `/terms`, `/review`) at 1440 and 390,
on a production build. Method: the impeccable detector, a scripted Playwright pass, and throttled performance
runs (Chromium, 4x CPU, 150ms RTT / 1.6 Mbps).

## What was checked and passed
- One H1 per page, no heading-level skips, `main` / `header` / `footer` landmarks, `lang="he" dir="rtl"`.
- Every control has an accessible name; no duplicate ids; every image has `alt`.
- Keyboard: every tab stop shows a focus ring; no traps; the skip link appears on focus.
- Reflow at 320 CSS px (400% zoom equivalent): no horizontal scroll on any page.
- Text spacing (WCAG 1.4.12) at 320px: no clipped text.
- Contrast: body text, hints and errors at or above 4.5:1 (existing e2e checks).
- No console errors or hydration warnings.
- CLS 0.000 on every page; LCP 1.0-1.5s on a throttled phone.

## Fixed in this pass
| Severity | Issue | Fix |
|---|---|---|
| P1 | 413KB of Zod plus the content validator in the client bundle, re-validating content on every visit | Client code reads `@content/data` (no Zod). Validation runs once on the server. Client JS on home went from 978KB to 580KB (−41%); TBT on legal pages dropped about 20% |
| P1 | On phones the accessibility button covered the copyright line at the bottom of every page | Footer clearance now includes the floating button (`--fab-space`) |
| P1 | The review thank-you sometimes never received focus (a timer could fire before React committed the state); screen-reader users missed the confirmation | Focus moves from a ref callback as the message mounts |
| P2 | Footer, header nav and brand links were 25-41px tall (older, mobile audience) | All are 44px targets |
| P3 | Two e2e checks read geometry mid-transition | Polled |

Guards added in `e2e/quality.spec.ts`: no `ZodError` in client JS, 44px link targets, no footer text under the
floating buttons.

## Tried and reverted (no measurable gain)
- Deferring Lenis to idle time: moved its layout cost but TBT did not drop.
- One Suspense boundary per section: split the hydration task but total TBT stayed about the same.
