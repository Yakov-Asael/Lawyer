# Google Business Profile: setup checklist

Goal: the office appears on Google Search and Maps for "עורך דין חדרה", "נוטריון חדרה" and related searches.
Verification must be done by the owner (Google sends a code or asks for a short video of the office).

## Before creating
- [ ] Search Google Maps for "שוקרון כהן חדרה" to make sure no profile already exists. If one exists, claim it instead.
- [ ] Use exactly the same details as the site and Golden Pages:
  - Name: עו״ד יוסי שוקרון כהן (no extra keywords in the name, Google penalizes it)
  - Address: הרברט סמואל 27, חדרה
  - Phone: 052-252-1127

## Profile fields
- [ ] Primary category: עורך דין (Lawyer)
- [ ] Additional categories: נוטריון, עורך דין לדיני משפחה, עורך דין לנזקי גוף, עורך דין לנדל"ן
- [ ] Opening hours
- [ ] Website: the new domain, once live
- [ ] Short description (up to 750 characters), same messaging as the site
- [ ] Photos: portrait, office exterior with signage, office interior, logo once ready
- [ ] Services list matching the four practice areas
- [ ] Enable WhatsApp / messaging if available

## After verification

- [ ] Update the Golden Pages listing if any detail differs
